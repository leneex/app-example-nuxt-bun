# Nuxt на Bun

Пример приложения [Nuxt](https://nuxt.com/) на [Bun](https://bun.sh/).

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/.output/public` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Railpack видит `bun.lock` и
собирает проект через Bun: `bun run build` запускает `nuxt generate`, готовые файлы — в
`.output/public`. В `nuxt.config.ts` выключен серверный рендеринг (`ssr: false`), страница
отрисовывается в браузере. Страница в демо одна, поэтому SPA не нужен — несуществующий адрес
отвечает 404. Если добавите страницы, включите SPA: с `ssr: false` Nuxt собирает одну
HTML-страницу, а остальные адреса открываются в браузере.

Пример с серверным рендерингом — `app-example-nuxt-ssr-bun`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
bun install

# запуск в режиме разработки
bun run dev

# сборка для продакшн
bun run build
```
